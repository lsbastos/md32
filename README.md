## Modelos Estatísticos (MD32)

Disciplina oferecida a alunos de terceiro ano de graduação do [IMPA Tech](https://impatech.edu.br/), obrigatória para alunos da ênfase em Inteligência Artificial e Ciência de dados .

### **Ementa**: 

Modelo de regressão linear, estimação, interpretação, diagnósticos, escolha de modelo, seleção de variáveis, previsão; Os modelos lineares serão estendidos levando a outras classes de modelos flexibilizando (i) a normalidade levando aos modelos lineares generalizados (GLM); (ii) a linearidade levando aos modelos aditivos generalizados (GAM); (iii) a independência via efeitos aleatórias trazendo os modelos lineares generalizados mistos (GLMM). Outras extensões do modelo linear serão apresentados como o modelo de sobrevivência, a regressão quantílica, entre outros.
